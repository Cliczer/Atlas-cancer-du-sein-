Aide

Mode d'emploi :
1. Cliquez sur un nœud (ou une question de la liste à gauche, ou une réponse de son menu déplié) pour le modifier dans le panneau de droite.
2. Une fois vos modifications faites dans le panneau de droite, cliquez sur « Valider » pour les appliquer à l'arbre.
3. La forme de l'arbre est calculée automatiquement : vous ne pouvez pas déplacer un nœud à la main, elle se réorganise toute seule dès que vous ajoutez/supprimez un élément.
4. Question vs Étape : Une Question peut avoir plusieurs réponses (branches). Une Étape permet soit une suite unique (flèche sans texte), soit de se diviser en plusieurs branches nommées (comme une question).
5. Si un nœud est sélectionné (en surbrillance), cliquer sur « + » crée directement le lien avec ce nœud. Sinon, utilisez « Relier deux nœuds » : cliquez le parent puis l'enfant.
6. Utilisez la barre de recherche pour retrouver un nœud par mot-clé : l'arbre se centre sur lui et le sélectionne pour modification immédiate.
7. Ctrl+Z pour annuler, Ctrl+Maj+Z pour rétablir.
8. Touche Suppr (ou Backspace hors champ texte) pour supprimer le nœud ou la branche sélectionné(e).

Relier une réponse aux études (matching) :
Cliquez sur une branche/réponse (le petit libellé sur la flèche). Dans le panneau de droite, section « Critères renseignés par cette réponse », ajoutez un ou plusieurs critères (ex. T = T2, et Age = 40 pour une même réponse). C'est ce qui permet à l'application de retrouver les études correspondant au profil du patient. Une réponse sans critère ne participe pas au matching.
Publier sur le site (recommandé) :
1. Choisissez le protocole (ou créez-en un et donnez-lui un nom de fichier).
2. Modifiez l'arbre, puis cliquez sur « Publier sur le site » : le protocole est écrit directement dans le dépôt Atlas. Un nouveau protocole est ajouté automatiquement au registre.
3. La première fois, collez un jeton GitHub (bouton « Jeton… ») : GitHub → Settings → Developer settings → Fine-grained tokens, permission « Contents: Read and write » sur le dépôt Atlas. Il reste enregistré uniquement dans ce navigateur.
4. Le site se met à jour tout seul (~1 min, après validation automatique).

Sans jeton (repli) : « Télécharger JSON » puis remplacez le fichier dans protocoles/ sur GitHub à la main.

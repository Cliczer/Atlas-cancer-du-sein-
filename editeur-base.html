Aide

Mode d'emploi :
1. Cliquez sur une étude dans la liste à gauche pour l'éditer à droite.
2. Une fois vos modifications faites, cliquez sur « ✓ Valider les modifications » pour les appliquer.
3. « + Étude » crée une étude vide. « ⧉ Dupliquer » copie l'étude actuellement sélectionnée (pratique pour des études très proches).
3b. Titre et Auteurs sont affichés séparément par l'Atlas (titre en gras, auteurs en plus petit dessous). Pour les études importées depuis l'ancienne citation unique, ce découpage a été fait automatiquement quand le format le permettait ; sinon les deux champs sont vides et l'Atlas affiche temporairement toute la « Référence brute » à la place — complétez Titre/Auteurs ici dès que vous éditez une de ces études.
4. Les critères cliniques (T, N, RE, RP, HER2, Grade, Ki67, Marges, Age, Emboles, Triple N, MCC) suivent la syntaxe du moteur de correspondance de l'Atlas : une valeur exacte (ex. 1), une plage 10-50, ou une comparaison <2, <=2, >2, >=2. Laissez -1 (valeur par défaut) si le critère n'est pas évalué par l'étude : il est alors totalement neutre — exclu du score et du badge « X/Y critères concordants » affiché sur l'Atlas, il ne compte ni comme un accord ni comme un désaccord. N'utilisez -1 que si l'étude ne dit vraiment rien sur ce critère ; sinon, le badge sous-comptera les critères réellement évalués.
5. Les résultats chiffrés affichés par l'Atlas sont une liste de mesures (ex. « OS à 5 ans », « OS à 10 ans »). Chaque mesure compare un nombre libre de bras / traitements que vous nommez vous-même (ex. « Chirurgie seule » 74 % vs « Chirurgie + RT » 82 %) — rien n'est codé en dur. Bouton « + Ajouter un traitement à comparer » pour chaque mesure. L'Atlas affiche tout ce qui est renseigné, ou rien. Le lien de l'article est aussi affiché tel quel.
6. Les résultats chiffrés (« outcomes ») sont des notes libres de travail, non affichées par l'Atlas : ajoutez autant de lignes nom/valeur que nécessaire avec « + Ajouter un résultat ».
7. La recherche filtre la liste en direct sur tous les champs (référence, objectif, niveau de preuve, lien, traitements, critères, résultats).
8. Ctrl+Z pour annuler, Ctrl+Maj+Z pour rétablir.

Publier sur le site (recommandé) :
1. Cliquez sur « Publier sur le site » : la base est écrite directement dans le dépôt Atlas.
2. La première fois, collez un jeton GitHub (bouton « Jeton… ») : GitHub → Settings → Developer settings → Fine-grained tokens, permission « Contents: Read and write » sur le dépôt Atlas. Il reste enregistré uniquement dans ce navigateur.
3. Le site se met à jour tout seul (~1 min, après validation automatique).

Sans jeton (repli) : « Télécharger JSON », puis remplacez base_etudes.json dans GitHub à la main.
Excel : « Télécharger Excel » génère un fichier base_etudes.xlsx avec une colonne par champ (référence, objectif, niveau de preuve, traitements, critères, lien, comparaison, puis tous les résultats rencontrés). Vous pouvez modifier ce fichier dans Excel puis le réimporter avec « Depuis mon ordinateur » : il remplacera entièrement la base actuellement chargée dans l'éditeur. Pensez ensuite à « Publier sur le site » pour publier le résultat — l'application utilise le JSON, pas l'Excel.

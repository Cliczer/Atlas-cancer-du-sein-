Aide

Mode d'emploi :
1. Cliquez sur une étude dans la liste à gauche pour l'éditer à droite.
2. Une fois vos modifications faites, cliquez sur « ✓ Valider les modifications » pour les appliquer.
3. « + Étude » crée une étude vide. « ⧉ Dupliquer » copie l'étude actuellement sélectionnée (pratique pour des études très proches).
4. Les critères cliniques matchables (T, N, RE, RP, HER2, Grade, Ki67 (%), Marges (mm), Age, Emboles, Triple N, MCC, RH) suivent la syntaxe du moteur de correspondance de l'Atlas : une valeur exacte (ex. 1), une plage 10-50, ou une comparaison <2, <=2, >2, >=2. Laissez -1 (valeur par défaut) si le critère n'est pas évalué par l'étude. Les champs AJCC, M, Mutation, Ménopause %, Marges et autres paramètres, Type histologique sont informatifs (texte libre, pas utilisés par le moteur de matching).
5. Les traitements évalués : cochez la case du traitement testé par l'étude, et précisez éventuellement un détail libre (molécule, dose, schéma) dans le champ associé.
6. Les détails de l'étude (méthode, type d'étude, population, inclusion/exclusion, échantillon, durée de suivi, données manquantes, limites, notes, autres interventions) sont du texte libre informatif, non utilisé par le moteur de matching.
7. Les résultats chiffrés (« outcomes ») sont entièrement libres : ajoutez autant de lignes nom/valeur que nécessaire avec « + Ajouter un résultat ».
8. La recherche filtre la liste en direct sur tous les champs (référence, citation, objectif, niveau de preuve, traitements, critères, détails, résultats).
9. Ctrl+Z pour annuler, Ctrl+Maj+Z pour rétablir.

Mise à jour GitHub :
1. Cliquez sur « Vers GitHub ».
2. Allez dans le dépôt GitHub de l'Atlas.
3. Supprimez l'ancien base_etudes.json.
4. Ajoutez le fichier téléchargé.
5. Vérifiez qu'il s'appelle exactement base_etudes.json.
6. Cliquez sur « Commit changes ».
Excel : « Télécharger Excel » génère un fichier base_etudes.xlsx avec une colonne par champ (référence, citation, objectif, niveau de preuve, détails de l'étude, traitements évalués + leurs détails, critères, puis tous les résultats rencontrés). Vous pouvez modifier ce fichier dans Excel puis le réimporter avec « Depuis mon ordinateur » : il remplacera entièrement la base actuellement chargée dans l'éditeur. Pensez ensuite à « Télécharger JSON » et « Vers GitHub » pour publier le résultat — l'application utilise le JSON, pas l'Excel.
